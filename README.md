# Desafios-criativos

Os dados foram gerados no Chat GPT e o resultado no Copilot.

**Prompt para o Copilot:**
Atue como analista de experiência do cliente em um banco. Sua tarefa é analisar o feedback de clientes bancários para identificar sua experiencia com o atendimento, serviços online, facilidade no uso de ferramentas e problemas encontrados.


O resultado será usado em um projeto publicitário para apoiar melhorias e resultar as vantagens do uso deste serviço.

resultado será considerado bom se for possível identificar com clareza e facilidade a experiencia do cliente e o quão comum é, e que mantenha consistência.

Contexto: Estou trabalhando com feedbacks de clientes bancários relacionados ao serviço de atendimento e sobre a usabilidade digital.

Dados disponíveis: A base contém comentários e reclamações.

Instruções de análise:

Classifique os feedbacks por tema, sentimento e frequência que ocorre.
Identifique os principais padrões, problemas, elogios e oportunidades nas experiencias relatadas.
Aponte evidências nos dados fornecidos.
Sugira ações práticas para a equipe de publicidade identificar como usar isso em anúncios ou campanhas.
Formato da resposta: A entrega deve conter tabelas com os principais feedbacks e sua incidência junto a recomendações de soluções.


Critérios de análise:

Use apenas os dados fornecidos.
Não invente números, causas ou conclusões.
Não exponha dados pessoais ou sensíveis.
Se houver informação insuficiente, indique a limitação.
Use linguagem simples.
